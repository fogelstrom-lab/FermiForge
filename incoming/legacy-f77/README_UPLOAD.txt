3He vortex modernization - legacy code drop

Place the original Fortran 77 source tree in this directory without
reorganizing or renaming it.

Please include, when available:

- all .f, .for, .inc, and header/include files
- Makefiles, compiler scripts, MPI launch scripts, and batch-job scripts
- representative input files and a small restart/checkpoint file
- one known-good output for a small calculation
- notes identifying the compiler, MPI implementation, libraries, and
  platform on which the code last ran
- any papers or notes that define the equations, units, order-parameter
  convention, phase winding, and boundary condition

Do not include credentials, private SSH keys, cluster tokens, or licensed
compiler/library files.

The original tree will be treated as read-only reference material.
Modernized code, tests, documentation, and migration notes will be kept
outside this incoming directory.
